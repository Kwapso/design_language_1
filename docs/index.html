Foundations

Four decisions carry the entire language.

It is flat

kwapso.com uses zero box-shadows across a 5,142px page. Depth is expressed by surface colour and space alone. A card is sand on paper — that colour step is the elevation. Only detached overlays may opt out.

One accent, held back

Mango means “this is the next action”. On a page of five thousand pixels it appears on eleven filled elements. A second accent on a view makes both mean “something”. The restraint is the brand.

Two faces, two weights

A condensed serif for statements, set at 0.8 line-height — negative leading is the most recognisable thing here. A grotesk for everything else, at 300 and 500. There is no bold.

Tracking opens, not tightens

Headings and labels carry +0.5px. That is the opposite of the tight-tracking default nearly every system ships, and it is a large part of why the brand reads as calm rather than urgent.

Colour

Eight brand values. Ink and paper carry every screen; mango is the single accent; sky, forest and poppy are marks — never section backgrounds.

Every pairing is verified, not assumed.

npm run check:contrast tests 30 text and non-text pairings against WCAG 2.1 on both surfaces, in both themes, and fails the build on a regression. Where a pairing sits below the floor on purpose — mango is a pale yellow and always will be — the exemption is printed with its reason on every run, so it has to be re-justified rather than quietly inherited.

Type

Fonts are not bundled.

Saans and Serrif Condensed are licensed typefaces; this repository has no right to redistribute them, so it ships none. Self-host them in your app and the language picks them up. Without them you are seeing the open fallback stack, which keeps the proportions and the feel.

Chat & AI

The assistant does not speak in a bubble.

Long generated text inside a tinted, rounded container is measurably harder to read than the same text set on the page. Bubbles suit short turns. So the user keeps a sand bubble — short, and findable when scrolling back — and the assistant gets the page. Neither is mango: an accent-coloured bubble would spend the view's one accent on every single message.

Where is our biggest operational bottleneck?
Quote-to-order is costing the most time — 21.25 hours a week across three people, against 12.5 for invoice approval.1 The delay sits in the manual re-keying between the CRM and the order sheet.

Cognitive load

Most design systems ship taste. This one ships constraints the build checks.

Run npx @kwapso/structure lint src/ — or node scripts/cognitive-load.mjs — over your views. Budgets live in tokens/tokens.json, so they are versioned and arguable in a pull request rather than buried in a script. Every rule can be suppressed inline with a reason, because a rule you cannot override is a rule people route around entirely.

RuleBudgetWhy
accent-budget1A second mango makes both mean “something”.
type-scale3Every size added is another thing the eye must rank.
grouping7Past seven, a list stops being scanned and starts being searched.
flatness2Only detached overlays may cast a shadow.
motion-budget400msBeyond this, motion reads as a wait, not as feedback.
touch-target44pxThe brand's control height and the WCAG floor agree.
hardcoded-value0A literal colour cannot be re-themed or dark-moded.
colour-only-meaning0Colour alone is invisible to about one man in twelve.

Density is a cognitive control, not a style

Marketing pages need air to feel considered; a dashboard someone works in all day needs proximity, so a scan is one movement instead of ten. One attribute switches the rhythm of an entire subtree — try the toggle in the header.

<div data-density="compact">…</div>

Adoption

Three doors. Take as much as you want.

1 — Reskin an existing app (one line)

Semantic HTML is styled for you. No markup changes, no build step, no framework.

<link rel="stylesheet" href="structure.css">

2 — Tokens only

Map the variables onto components you already have.

@import "@kwapso/structure/tokens.css";

.my-button { background: var(--st-accent); border-radius: var(--st-radius-pill); }

3 — Tailwind or React

// tailwind.config.js
module.exports = { presets: [require("@kwapso/structure/tailwind")] }
import { Button, Card, Chat } from "@kwapso/structure/react"
import "@kwapso/structure/structure.css"
